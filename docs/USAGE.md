# 使用说明

## 1. 导入 HTML

打开 `index.html` 后，点击：

**文件 / 版本 → 导入 HTML**

选择一个 HTML 文件。编辑器会将它加载到中间画布。

如果导入的是 PPT 风格的多页 HTML，左侧会出现 Pages / Slides。

---

## 2. 选择和编辑元素

点击画布中的元素后，右侧 Inspector 会根据元素类型显示可编辑字段。

常见类型：

- 文字
- 表格
- 图片
- 视频
- 按钮
- 下拉框
- 底框 / 图形
- 原型组件

拖动蓝色选框可移动元素，拖动控制点可以修改元素宽高。

---

## 3. 编辑文字

文字可修改：

- 内容
- 字号
- 字重
- 颜色
- 对齐
- 行高
- 字间距
- 是否换行

如果某些原始 HTML 使用了复杂嵌套结构，建议先点击最接近实际文字内容的节点。

---

## 4. 编辑 PPT 页面

文档 / PPT 模式左侧支持：

- 新增
- 复制
- 上移
- 下移
- 删除
- 拖动排序

页面操作不会覆盖最初导入的原文件。

---

## 5. 创建产品 / 游戏原型

切换到：

**交互原型设计**

然后：

1. 新建界面。
2. 左侧“组件库”添加组件。
3. 在画布中调整位置、尺寸、颜色和文案。
4. 选择可交互组件。
5. 右侧配置“原型交互”。
6. 使用“跳转页面 / 幻灯片”建立页面关系。
7. 切换左侧“界面关系”查看 Screen Flow。
8. 点击“交互预览”验证流程。
9. 导出 HTML 交付。

---

## 6. 本地视频

点击：

**+ 本地视频**

选择 MP4 / WebM / OGG 等视频。

也可以在右侧视频属性中替换本地文件。

本地视频在 HTML 导出中会以内嵌 Data URL 方式保存，因此无需额外视频目录即可打开 HTML，但文件体积也会随之增加。

---

## 7. PDF + 视频包

### 第一步：保存浏览器原生 PDF

点击：

**PDF + 视频包（原生）**

编辑器会：

1. 扫描全部视频。
2. 固定视频唯一 ID。
3. 生成打印用页面。
4. 打开浏览器打印窗口。

在打印窗口中：

- 目标打印机：**另存为 PDF**
- 每页打印页数：**1**
- 边距：**无**
- 打开“背景图形”
- 保存 PDF

如果文档是 38 页，打印预览也应该显示 38 页。

### 第二步：回填视频链接并打包

保存 PDF 后返回编辑器。

编辑器会显示“PDF 导出第 2 步”。

点击：

**选择已保存 PDF**

选择刚保存的 PDF。

完成后会下载最终 ZIP。

### 最终文件结构

```
xxx_PDF视频包_最终.zip
├─ xxx.pdf
├─ README.txt
├─ 视频清单.txt
└─ videos/
   ├─ video_01.mp4
   ├─ video_02.mp4
   └─ ...
```

### 正确打开方式

1. 完整解压 ZIP。
2. 确保 PDF 和 videos 文件夹同级。
3. 打开 PDF。
4. 点击视频入口。
5. 如果阅读器询问是否允许打开本地文件，选择允许。

---

## 8. PPTX 导出

点击顶部：

**PPTX**

PPTX 导出目标是“可继续编辑”，因此复杂浏览器效果会进行近似转换。

推荐检查：

- 渐变底框
- 透明度
- 圆角
- 阴影
- 字体
- 图片裁切
- 表格
- 复杂 CSS 特效

如果目标是视觉完全一致，优先使用 PDF；如果目标是后续在 WPS / PowerPoint 修改，使用 PPTX。

---

## 9. 原型交互建议

产品 / 游戏策划常见流程：

```
组件库搭界面
    ↓
给按钮设置组件名称
    ↓
配置触发方式
    ↓
设置跳转页面 / 打开弹窗 / 切换状态
    ↓
界面关系查看 Screen Flow
    ↓
交互预览
    ↓
导出 HTML
```

建议把一个完整功能拆成多个界面，例如：

```
主页
 ├─ 商店
 │   ├─ 商品详情
 │   └─ 购买确认弹窗
 ├─ 背包
 └─ 设置
```

这样 Screen Flow 更清晰。

## 10. 常见问题

### 为什么 PDF 点击视频没有反应？

检查：

1. 是否打开的是“最终 ZIP”里的 PDF。
2. ZIP 是否已经完整解压。
3. PDF 是否与 videos 文件夹同级。
4. videos 文件夹是否真的存在对应视频。
5. WPS / Acrobat 是否拦截本地文件链接。

### 为什么远程视频没有被打包？

如果视频服务器禁止跨域读取，浏览器无法直接下载视频内容。编辑器会保留 URL 引用说明。

### 为什么 PPTX 和 HTML 看起来不完全一样？

HTML 使用浏览器 CSS 渲染；PPTX 使用 PowerPoint / WPS 的图形系统，两者并非同一个渲染引擎。复杂 CSS 只能做近似转换。

### 为什么导入大型 HTML 后编辑器变慢？

页面节点很多、图片很大或本地视频以 Data URL 内嵌时，DOM 和文件体积都会增大。建议分阶段保存版本，并避免一次嵌入过多超大视频。
